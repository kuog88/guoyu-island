# 國語闖關島

國小一～六年級上學期國語的互動闖關遊戲，支援南一、康軒、翰林三個版本（115 學年度），以手機、平板為主。

## 內容

- **一年級全文注音**：題目、選項、提示、說明文字的每個國字右邊都有注音（會洩漏答案的選項和要拼的字除外）。多音字、輕聲依詞語判斷，以教育部最新審訂音為準，再逐句人工校對。
- **一、二年級**：認字、注音拼音（撈魚拼注音、聲調貝殼）、筆順描寫（一年級）、看注音寫國字、句子填空。一年級第一次月考是注音拼音群島。
- **三～六年級**：以考卷常見題型為主，每課 20 題、題型隨機穿插：
  - 字詞：看注音寫國字、錯字偵探、量詞配對（中年級）
  - 句式：成語（拼圖、情境選用、選意思、誤用辨別）、選詞填空、關聯詞、句子重組、修辭（高年級）、句子變身（高年級）、標點、句意、換句話說
  - 加強練習：成語練習、句型練習，可選第一次月考範圍、第二次月考範圍或全冊
- **五、六年級**：閱讀加強區（每課一篇自編短文）。
- **家長報表**：常錯的字、題型答對率、各課進度、考前複習關卡。
- 同一關不會重複出現同一個字詞、成語或句子；最近玩過的題目會往後排。

## 📝 月考測驗卷

地圖頁最下面的「📝 月考測驗卷」欄位，畫面與計分由遊戲樂園共用的 `kg-exam.js` 負責（正式試卷，不是遊戲；80 分 ★、90 分 ★½、100 分 ★★）。
題庫由 `make_exam.py` 從各課生字、語詞、句子產生，放在 `game/exam/g1～g6.json`，每個年級、每個版本各一份；`check_exam.js` 依規格檢查。

- **試卷**：每個版本 3 份——第一次月考、第二次月考（課次依各版本對半分）、全冊總複習。一年級第一次月考考注音符號（聲調、二拼音、三拼音、聲母介音韻母），第二次月考考課文生字。
- **題型**：是非、選擇、填充（填充用點選字卡，不用打字）。
  - 選擇：語詞中某字的注音、看注音選國字、部首、哪個語詞用字正確／有錯字、哪個注音「不正確」、選詞填空（三年級以上）
  - 是非：部首敘述、語詞注音、語詞用字
  - 填充：看注音寫國字、筆畫數、句子填空
- **陷阱**：聲調差一點、形近注音符號（ㄅㄆㄉ、ㄢㄤ…）、同音字（不同調也算）、形近字、「不正確的是哪一個」。錯誤選項都排除該字的其他合法讀音，換進語詞也不會變成真的詞，保證只有一個正確答案。
- **一年級**：題目說明文字加注音，考的字和選項不加，避免洩漏答案。

## 檔案

| 檔案 | 用途 |
|---|---|
| `game/` | 可以直接部署的遊戲：`index.html`、`data/g1～g6.json`、`strokes/g1.json` |
| `game_template.html`、`game_script.js` | 遊戲的樣式與程式原始碼 |
| `build_game.py` | 把資料和程式組成 `game/` |
| `lessons_115_1.json`、`lessons_114_2.json` | 各版本各課的生字、認讀字、語詞（教育百科生字詞彙表） |
| `char_info_all.json`、`word_zy.json`、`char_info_g1.json` | 注音、部首、筆畫（教育部字典） |
| `stroke_count.json` | 教育部筆順網的筆畫數（g0v/zh-stroke-data）；字卡筆畫和描寫筆數用它統一（`fetch_stroke_count.py`） |
| `radical_textbook.json` | 課本（康熙）歸部和教育部字典不同的字（例如最：曰，教育部歸冂），以課本為準出題、字卡註記教育部歸部 |
| `strokes_g1.json` | 一年級筆順與字形（g0v/zh-stroke-data 教育部標準字形；只有資料有誤的字才用 Make Me a Hanzi） |
| `game/fonts/twkai.woff2` | 全字庫正楷體切出遊戲用到的字，各裝置字形一致（`make_font.py`，原始字型放 `fonts_src/`，不進版本庫） |
| `make_zy_g1.py`、`zy_fix_g1.json` | 一年級全文注音：找最長的詞決定多音字讀音（教育百科 > 教育部國語辭典修訂本 g0v/moedict-data > 單字讀音），`zy_fix_g1.json` 是人工校對的詞語、單字讀音與不採用的詞；`zy_g1_review.txt` 逐句列出讀音供校對 |
| `fetch_zy_words_g1.py`、`word_zy_pedia_g1.json` | 到教育百科查一年級畫面上出現的詞語最新讀音 |
| `make_exam.py`、`check_exam.js`、`game/exam/` | 📝 月考測驗卷題庫與檢查程式 |
| `bank_g3.txt`～`bank_g6.txt` | 各年級共用題庫（成語、關聯詞、量詞、修辭、句子變身、標點、句意、換句話說），自編 |
| `lessons_g{3-6}_{nani,kang,han}.txt` | 各版本各課的選詞填空、句子積木，自編 |
| `sentences_g1.txt` | 一年級句子填空，自編 |
| `reading_g5.txt`、`reading_g6.txt` | 五、六年級閱讀短文與題目，自編 |
| `scrape_lessons.py`、`fetch_info_all.py`、`fetch_strokes.py` | 重新抓取課文字詞、字典資料、筆順的程式 |
| `*.html`（根目錄） | 版本比對、規劃、審閱頁等文件 |

## 修改題目後重新產生遊戲

```bash
python build_game.py
```

產生的 `game/` 資料夾放到任何靜態網站空間（例如 GitHub Pages）即可使用。

## 資料來源與授權提醒

- 課文生字、語詞：教育部教育百科「生字詞彙表」。
- 注音、部首、筆畫：教育部字典；筆畫數以教育部筆順網為準；部首以課本（康熙）歸部為準，比對用 Unicode Unihan 15.0 kRSKangXi。
- 筆順字形：g0v/zh-stroke-data（教育部常用國字標準字體筆順），少數字用 Make Me a Hanzi（hanzi-writer-data）。正式商用前請向教育部確認授權。
- 楷體字型：全字庫正楷體 TW-Kai（國家發展委員會全字庫，政府資料開放授權條款第 1 版）。
- 題庫、閱讀短文、句子都是自編，未使用課本原文或出版社試題。
